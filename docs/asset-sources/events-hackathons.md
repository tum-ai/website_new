# Earlier hackathon event assets

File paths below are relative to `public/assets/events/hackathons/`. These are the posters and
photos of the redesign-only events (`redesignOnlyEvents` in `src/lib/mock-cms.ts`): hackathons
from before the CMS events start (August 2025). The mock CMS shows them, and the backfill uploads
them to the `redesign` dataset.

Retrieved 2026-10-01 from TUM.ai's own LinkedIn posts. Images are encoded as WebP at their
original size, without edits.

- `benchpress-makeathon-poster.webp`: the announcement poster of "TUM.ai x Aleph Alpha: BenchPress Makeathon",
  https://www.linkedin.com/posts/tum-ai_alephalphahackathon-aiinnovation-phariamodels-activity-7259467060093603841-qu1g
- `benchpress-makeathon-group.webp`: the group photo from the recap post,
  https://www.linkedin.com/posts/tum-ai_tumaix-aleph-alpha-benchpress-makeathon-activity-7269986457535008768-r4On
- `tensor-tournament-2024-poster.webp`: the TUM.ai poster for "The Tensor Tournament T3 2024",
  https://www.linkedin.com/posts/tum-ai_thetensortournament-t3-aihackathon-activity-7180834874352623616-ZR3B
